# Колористика/тональный метод

**контраст, высокий, сочетание.** Внешности с высоким контрастом (тёмные волосы + светлая кожа) идут контрастные сочетания: чёрный с белым, тёмная база с ярким акцентом. _(источник: Тональный метод (dominant characteristic))_

**контраст, низкий, нюанс, сочетание.** Внешности с низким контрастом идут нюансные тональные сочетания близких по светлоте цветов; резкий чёрно-белый контраст «спорит» с внешностью. _(источник: Тональный метод)_

**контраст, средний, сочетание.** При среднем контрасте внешности работает умеренный контраст образа: спокойная база плюс один цветовой акцент. _(источник: Тональный метод)_

**подтон, тёплый, нейтралы.** При тёплом подтоне кожи базовые нейтралы — кремовый, кэмел, коричневый, тёплый беж; золото уместнее серебра. _(источник: Тональный метод)_

**подтон, холодный, нейтралы.** При холодном подтоне кожи базовые нейтралы — серый, чёрный, белоснежный, холодный синий; серебро уместнее золота. _(источник: Тональный метод)_

**подтон, нейтральный.** Нейтральный подтон допускает обе температуры цвета — важнее следить за чистотой/приглушённостью оттенка под тип внешности. _(источник: Тональный метод)_
